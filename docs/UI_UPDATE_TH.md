# อัปเดตหน้าจอง Student Performance Report

1. เปลี่ยนหัวข้อในกล่องบนเป็น Student Performance Report และขึ้นบรรทัดใหม่ด้วยข้อความ ประชุมรับผลการเรียนประจำ Cycle August - November 2026 ใช้ตัวอักษรขนาดเดียวกัน สีดำทั้งสองส่วน
2. เพิ่มคำอธิบายใต้หัวข้อเลือกช่วงเวลา: 1 ครอบครัวจะมีเวลา Consult บ้านละ 10 นาที เมื่อใกล้ถึงเวลาเจ้าหน้าที่จะติดต่อกลับไป
3. ขยายข้อความกล่อง Beginner ของทุกวิชา ใช้วันแบบตัวหนาและเวลาเด่นสีแดง พร้อมคงช่องยืนยันที่มองเห็นสถานะชัดเจน

แตกไฟล์ SPR_Queue_UI_Email_Update.zip แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดทับที่ root ของ teaching01-netizen/SPR_Queue กด Commit changes และรอ Railway Deploy สำเร็จ จากนั้นโหลดหน้าจองใหม่

ตาราง 6–7 พฤศจิกายนในชุดนี้เป็นฉบับที่แก้ถูกต้องแล้ว: วันที่ 6 ใช้เวลาเดิม วันที่ 7 ใช้เวลาใหม่ รวม 82 slots การรีเฟรชยังทุก 5 วินาที และการอัปเดตไม่ล้างข้อมูลหรือเปลี่ยนรหัส Staff

การส่งอีเมลใช้แม่แบบเดิมใน backend/internal/consult/email_template.go พร้อมช่วงเวลาและปุ่มติดตามคิว อ่านขั้นตอนเปิดส่งจริงใน EMAIL_SETUP_TH.md ขณะจัดทำชุดนี้ยังขาดบัญชี Resend/โดเมนผู้ส่ง/API Key จึงยังไม่ได้เปิดส่งจริงบน Railway
