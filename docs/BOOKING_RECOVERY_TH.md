# คืนสถานะและคืนที่ว่างเฉพาะราย — 4 November 2026

ฟังก์ชันนี้เพิ่มในอัปเดต Booking Recovery ต้องอัปโหลดโค้ดเข้า GitHub และรอ Railway Deploy สำเร็จก่อนใช้งาน บนรอบจริงใช้บัญชี Admin (RD1) ปุ่มจะไม่แสดงให้บัญชี operator

## เอารายการทดสอบออก เช่น Tar

1. เข้าหน้า Staff แล้วค้นหาชื่อหรือ Wcode ตรวจสอบวัน เวลา วิชา และรหัสคิวให้ตรงกับรายการทดสอบ
2. ถ้าจบเคสหรือเก็บประวัติแล้ว เปิดแท็บ **รายการจบแล้ว** ซึ่งรวมรายการที่เก็บไว้ด้วย
3. กด **คืนสถานะ / คืนที่ว่าง** เลือก **ยกเลิกรายการนี้และคืนที่ว่าง**
4. ใส่เหตุผล เช่น “ทดลองระบบ” ติ๊กยืนยันชื่อที่เลือก แล้วกดยืนยัน

ที่ว่างในช่วงเวลานั้นจะคืนหนึ่งที่ แม้เคยกดจบเคสแล้ว รายการย้ายไปแท็บยกเลิก ไม่อยู่ใน Excel หรือข้อมูลที่ซิงค์ไป Google Sheets รอบถัดไป (ตามปกติประมาณ 15 วินาทีเมื่อการเชื่อมต่อทำงาน) ประวัติเดิมยังอยู่ใน audit ไม่มีการลบข้อมูลคนอื่นหรือส่งอีเมลยืนยันซ้ำ งานเมลของรายการนี้ที่ยังไม่ส่งจะถูกยกเลิก

**เก็บรายการจบแล้ว** เป็นเพียงการซ่อนรายการจากหน้าหลัก จึงไม่คืนโควตา ใช้การยกเลิกด้านบนเมื่อต้องการคืนที่ว่าง

## คืนผู้ปกครองจริงกลับเป็นรอเช็กอิน

1. ค้นหารายการของผู้ปกครองจริง ตรวจสอบชื่อ Wcode และรหัส เช่น B-V-003
2. เปิด **คืนสถานะ / คืนที่ว่าง** เลือก **คืนเป็นรอเช็กอิน · ใช้รหัสคิวเดิม**
3. ถ้าเป็น Math + Verbal เลือกวิชาที่จะเริ่มก่อน ใส่เหตุผลและติ๊กยืนยัน แล้วบันทึก
4. รายการกลับมาที่หน้าเช็กอิน ต้องเช็กอินและจัดลำดับคิวใหม่ก่อนเรียก

เก็บชื่อ ข้อมูลการจอง วันเวลา วิชา รหัสคิวเดิม และลิงก์ติดตามเดิม ล้างการเช็กอิน การเรียก/ปรึกษาที่ทดลอง ลำดับคิว ห้อง และสถานะจบ/เก็บ/ยกเลิกเฉพาะรายการนั้น พร้อมเก็บข้อมูลก่อนแก้ใน audit หากคืนรายการที่เคยยกเลิกแล้วแต่ช่วงเวลาเต็ม ระบบจะไม่ยอมให้คืนจนกว่าจะมีที่ว่าง

## เลขคิวไม่เริ่มใหม่

B-V-001 และ B-V-003 ของผู้ปกครองจริงจะยังเป็นเลขเดิม การยกเลิก Tar ไม่ทำให้รหัสที่ยกเลิกถูกนำไปใช้ซ้ำกับคนใหม่ และไม่จัดเลขใหม่ให้คนอื่น รายการใหม่ใช้เลขถัดไปตามปกติ การจัดลำดับการเรียกทำแยกจากรหัสประจำรายการ

## ขอบเขต

- ทำงานเฉพาะหนึ่งรายการต่อครั้ง ต้องมีสิทธิ์ Admin เหตุผล และการยืนยัน
- ถ้ารายการเปลี่ยนระหว่างเปิดหน้าต่าง ระบบปฏิเสธการบันทึก ให้ปิดแล้วเปิดรายการล่าสุดอีกครั้ง
- ถ้าระบบกำลังส่งเมลของรายการนั้น ให้รอแล้วลองใหม่
- ไม่รีเซ็ตฐานข้อมูล ไม่คืนฐานข้อมูลทั้งระบบ ไม่แก้รหัส/ข้อมูลของผู้ปกครองรายอื่น และไม่ส่งอีเมลซ้ำ
- ตัวเลือกในเครื่อง local-test เดิมมีสิทธิ์เป็น operator; ใช้ Admin ที่เตรียมไว้สำหรับการทดสอบสิทธิ์หากต้องการทดสอบปุ่มนี้
