# จำนวนคิวที่เหลือ — Warwick Private Consult

หน้าติดตามส่วนตัวคำนวณจากลำดับปัจจุบันของห้อง Math / Verbal เช่น กำลังเรียกคิว1 → คุณคิว5 แสดง **เหลืออีก 4 คิวถึงคุณ** ถ้าพร้อมเป็นคิวถัดไปแสดง 1; เมื่อ Staff เรียกหรือเริ่มปรึกษาคิวของคุณแสดงถึงคิวแล้ว (API=0)

ไม่ลบเลขรหัสคิวมาคำนวณ เพราะรหัสคงเดิมแม้สลับลำดับ เปลี่ยนรอบ ส่งต่อวิชา หรือมีคนถูกยกเลิก

ระบบนับรายการ Waiting ที่เช็คอิน มีรหัสและลำดับในห้องปัจจุบันแล้ว โดยเรียงรอบตามเวลาและลำดับที่ Staff บันทึกภายในรอบ นับคิวที่ยังต้องถูกเรียกจนถึงตัวเองรวมตัวเองด้วย อ้างอิงรอบของคิว active หรือคิวที่ถูกเรียกล่าสุด; รอบถัดไปนับรายการที่พร้อมในรอบก่อนหน้าตามช่วงที่เหลือด้วย

- ยังไม่เช็คอิน: แสดงให้เช็คอินก่อน ค่ายังเป็น null
- ยังไม่จัดลำดับ รวม Combined เพิ่งย้ายห้อง: แสดงกำลังจัดลำดับ ค่ายังเป็น null
- No-show/Cancelled/Completed ไม่นับเป็นคนที่รอก่อนคุณ และไม่แสดงจำนวนเมื่อเป็นสถานะของตัวคุณเอง
- Math + Verbal นับเฉพาะวิชาปัจจุบัน หลังจบวิชาแรกต้องจัดลำดับในห้องใหม่ก่อน
- Staff ข้ามไปเรียกรอบหลังแล้ว แต่คุณยังรอในรอบก่อนหน้า: แสดงให้ติดต่อ Staff แทนจำนวนที่อาจผิด
- Staff สามารถเลือกเรียกต่างจากลำดับได้ ตัวเลขจึงเป็นจำนวนตามลำดับ ณ ตอนนี้ อัปเดตทุก5วินาที และเปลี่ยนเมื่อมีการจัดใหม่ ไม่ใช่เวลาประมาณเป็นนาที

จอรวมยังคงแสดงสองคิวถัดไปต่อห้อง หน้าติดตามส่งเฉพาะจำนวน สถานะ และรหัส ไม่เปิดชื่อ/contact/คำถามของนักเรียนคนอื่น

## รุ่นทดสอบพักส่งเมล

ใช้ `Warwick_Queue_Test.sh` ใน Downloads แล้วรัน `bash ~/Downloads/Warwick_Queue_Test.sh` จากโฟลเดอร์โปรเจกต์เดิม เปิดครั้งต่อไปด้วย `bash scripts/queue-test.sh` รุ่นนี้ใช้ Compose override ปิด SMTP แม้มีค่าเดิม เก็บฐานข้อมูลและ config เดิม ไม่ถาม App Password อีเมลค่อยตั้งค่าตอน Deploy

## อัปเดต

ดาวน์โหลด `Warwick_Update_Queue_Count.sh` ไว้ Downloads เปิด Docker Desktop และ Terminal ในโฟลเดอร์โปรเจกต์เดิม:

```bash
bash ~/Downloads/Warwick_Update_Queue_Count.sh
```

เก็บ config, booking, tracking token, queue, Staff users และ SMTP settings ไม่ reset ฐานข้อมูล

หากมี App Password ของบัญชีผู้ส่ง Warwick แล้ว อัปเดต+ตั้งค่า+ส่งเมลทดสอบด้วย:

```bash
bash ~/Downloads/Warwick_Update_Queue_Count.sh --setup-warwick-email
```

กรอก App Password บนเครื่อง ระบบไม่แสดงรหัสและไม่ใส่ในไฟล์แจกจ่าย ดูขั้นตอนสร้างใน `EMAIL_SETUP_TH.md`
