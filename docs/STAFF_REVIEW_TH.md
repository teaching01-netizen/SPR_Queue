# ปรับหน้า Staff และรายการเหตุการณ์ที่ต้องตัดสินใจ

วันที่ตรวจ: 14 ตุลาคม 2026 · สำหรับระบบทดสอบในเครื่อง

## สิ่งที่ปรับในรุ่นนี้

- ตัวเลือกระดับ Beginner / High Level แสดงสีและเครื่องหมายเลือกชัดเจน
- ช่องยืนยันสัมมนา Beginner มีกรอบ เครื่องหมายถูก และข้อความ “ยืนยันแล้ว / ยังไม่ได้ยืนยัน” ใช้เมาส์และคีย์บอร์ดได้
- หน้า Staff เริ่มที่ **เช็กอิน · รวมทุกช่วงเวลา** รวมทุกวันและทุกระดับ แบ่ง Section ตามวัน + ระดับ + รอบ ค้นหาชื่อ / Wcode / รหัสคิว / โรงเรียน / Email แล้วเช็กอินได้โดยไม่ต้องเลือกช่วงเวลาก่อน
- ตัวกรอง **All / SAT Math / SAT Verbal / Math + Verbal** ใช้ **วิชาที่จอง**: Math และ Verbal วิชาเดียวไม่รวม Combined
- ปุ่ม **เปิดคิวรอบนี้** เลือกระดับ วัน รอบ ห้อง และวิชาที่จองให้ตรงกับรายการนั้น
- หน้า **จัดคิว / เรียกคิว** แยกห้องที่ให้บริการ Math / Verbal ออกจากวิชาที่จอง; ภาพรวมคิวที่กำลังใช้ห้องยังแสดงแม้ถูกซ่อนจากตัวกรองรายการ เพื่อไม่ให้เข้าใจว่าห้องว่าง
- Math + Verbal เลือกเริ่ม Math หรือ Verbal ก่อนเรียกคิวครั้งแรกได้ มีหน้าต่างยืนยัน และแสดงความคืบหน้าทั้งสองวิชา
- ค่าตั้งต้นสำหรับ Combined ใหม่ยังเป็น Math ก่อน; Staff เปลี่ยนเป็น Verbal ก่อนได้ ไม่แก้ประวัติการให้บริการย้อนหลัง
- จบวิชาแรกแล้วกลับเข้า Waiting ของอีกวิชา; Staff จัดลำดับห้องที่สองก่อนเรียก รหัสคิว / booking / check-in เดิมคงอยู่ จบทั้งสองวิชาจึง Completed
- เปลี่ยนวิชาเริ่มต้นแล้วลำดับห้องเดิมถูกล้าง ต้องจัดคิวในห้องใหม่; ปุ่มเปลี่ยนวิชาแรกโดยตรงล็อกหลังเคยเรียก; รุ่นแก้รายการเปิดให้พักคิวแล้วแก้ก่อนเริ่มปรึกษา โดยต้องจัดคิวใหม่
- การจัดลำดับต้องเห็นผู้รอในห้อง/รอบนั้นครบ หากมีตัวกรองซ่อนบางคน จะให้กด “ดูทั้งหมดเพื่อจัดลำดับ”; การเรียกถัดไปเป็น **ถัดไปตามตัวกรองที่แสดง**

## วิธีลอง Math + Verbal โดยเริ่ม Verbal

1. จอง Math + Verbal และเข้า Staff > เช็กอิน · รวมทุกช่วงเวลา
2. ค้นหารายการ กดเช็กอิน แล้วกด **เริ่ม Verbal ก่อน** และยืนยัน
3. กด **เปิดคิวรอบนี้** > **บันทึก / จัดคิว** > **เรียกคิว** > **เริ่มปรึกษา**
4. กด **จบ Verbal → Math**
5. เปลี่ยนห้องที่ให้บริการเป็น Math เลือกรอบเดิม แล้ว **บันทึก / จัดคิว** อีกครั้ง
6. เรียก > เริ่ม > จบการปรึกษา ตรวจว่าทั้ง Math และ Verbal แสดง “เสร็จแล้ว” และรหัสคิวคงเดิม

## Error ที่ระบบมีตัวป้องกันอยู่แล้ว

## แก้การจองเดิม / เอาออก / คืนการจอง

- ค้นหารายการใน Staff แล้วกด **แก้วัน / เวลา / วิชา** เลือกวิชา วัน รอบ และยืนยันสัมมนา Beginner ให้ตรงกับวิชาใหม่ บันทึกแล้วใช้ booking และลิงก์ติดตามเดิม
- แก้ได้ก่อนเริ่มปรึกษา รวม Booked / Waiting / No-show / รายการยกเลิกที่ยังไม่ได้เริ่ม หากกำลัง Calling ให้กดพักคิวก่อน รายการที่เคย Serving หรือจบวิชาใดแล้วแก้วิชา/รอบไม่ได้ เพื่อเก็บประวัติการให้บริการ
- เปลี่ยนเวลาในวันเดิมเก็บ check-in และรหัสคิวไว้ แต่ต้องจัดลำดับใหม่ เปลี่ยนวันจะกลับรอเช็กอินวันใหม่
- เปลี่ยนวิชาจะล้างรหัสคิวเดิม และออกเลขใหม่ที่ตรงวิชาเมื่อกดบันทึก / จัดคิว; เลขเก่าไม่ถูกนำกลับมาใช้ ลิงก์ติดตามเดิมยังใช้ได้
- กด **เอาออก / ยกเลิก** ระบุเหตุผล เช่น **ไม่มา / ไม่แจ้งยกเลิก** รายการจะออกจากหน้าทำงานและคืน slot โดยเก็บไว้ในแท็บ **รายการยกเลิก** พร้อมเหตุผล
- เปิดแท็บ **รายการยกเลิก** แล้วกด **คืนการจอง** > **ยืนยันคืนการจอง** ระบบตรวจโควตาใหม่ หากเต็มจะไม่คืนเกินจำนวน และไม่สร้างรายการใหม่
- หากรอบเดิมเต็มหรือถูกถอด เลือก **วัน / เวลา / วิชาอื่น** จากหน้าคืนรายการ หรือแก้รายการที่ยกเลิกก่อนแล้วคืนใหม่ การแก้รายการยกเลิกยังไม่สำรอง slot
- คืนรายการที่เคยเช็กอินแล้วในวันเดิม → Waiting; ยังไม่เช็กอิน → Booked. ลำดับคิวเดิมไม่คืนอัตโนมัติ ต้องจัดใหม่ก่อนเรียก
- Combined ที่จบวิชาแรกแล้วและยกเลิกระหว่างรอ คืนได้เมื่อรอบเดิมมีที่ว่าง โดยกลับไปรอวิชาที่เหลือและเก็บ stage เดิม แต่แก้วิชา/รอบหลังใช้บริการแล้วไม่ได้
- กรณีเปิด SMTP จะเข้าคิวส่งอีเมลยืนยันล่าสุดหลังแก้หรือคืน; โหมด local-test ยังคงปิด SMTP
- ทุกการแก้ ยกเลิก และคืนบันทึก Staff กับข้อมูลก่อน/หลังใน audit; ยังไม่เพิ่มการลบทิ้งถาวรหรือการเปิด Completed กลับมา

ดาวน์โหลด **Warwick_Update_Bookings.sh** ไว้ใน Downloads เปิด Docker Desktop แล้วรัน:

```bash
bash ~/Downloads/Warwick_Update_Bookings.sh
```

รอเปิดระบบเสร็จแล้วรีเฟรชหน้า Staff ตัวอัปเดตสำรอง source และเก็บรหัส Staff, event config และ database เดิมไว้

ประเด็นที่ปรับตามคำขอใหม่: แก้วัน/รอบ/วิชาจากรายการเดิม และคืน Cancelled (ส่วนหนึ่งของ R10/R12/R13/R17). R09 เรื่องโควตาเมื่อยกเลิกหลังใช้บริการบางส่วน และการ Undo Completed ยังคงเป็นข้อที่ต้องตัดสินใจต่อ ไม่ได้เพิ่มวิธีแก้ในรุ่นนี้
