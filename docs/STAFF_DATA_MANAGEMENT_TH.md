# จัดการรายการจบแล้วและข้อมูลทดสอบ

## ทำไมจบเคสแล้วแก้รอบ/วิชาไม่ได้

รายการ Completed มีประวัติการปรึกษาจริงแล้ว เปลี่ยนรอบ/วิชาหรือเปิดคิวเดิมใหม่จะทำให้ประวัติและรายงานผิด จึงยังล็อกส่วนนี้ไว้ แต่เพิ่มวิธีเก็บรายการและจัดการข้อมูลทดสอบให้

| สิ่งที่ทำ | โหมดเทสในเครื่อง (เมลปิด) | รอบจริง |
| --- | --- | --- |
| เปิดดูรายการจบแล้ว | ได้ | ได้ |
| เก็บรายการจบแล้วออกจากหน้าทำงาน | ได้ | ได้ |
| นำรายการที่เก็บกลับมาแสดง | ได้ สถานะยังเป็น Completed | ได้ สถานะยังเป็น Completed |
| ลบรายการถาวร รวม Completed | ได้ หลังยืนยัน | ไม่เปิดใช้ |
| ล้างการจองทั้งหมดของงานปัจจุบัน | ได้ หลังพิมพ์ยืนยัน | ไม่เปิดใช้ |
| เปลี่ยน Completed ให้กลับมาเรียกใหม่ | ไม่เปิดใช้; ถ้าจะเทสใหม่ลบแล้วจองใหม่ได้ | ไม่เปิดใช้ |

## รอบจริง: เก็บประวัติแทนการลบทิ้ง

1. Staff เปิดแท็บ **รายการจบแล้ว** หรือรายการ Completed ที่ยังแสดงในหน้าคิว
2. กด **เก็บรายการจบแล้ว** รายการออกจากเช็คอิน/หน้าคิว แต่ยังค้นหาได้ในแท็บรายการจบแล้ว
3. เลือกตัวกรอง **เก็บประวัติแล้ว** เพื่อดูเฉพาะที่เก็บ
4. กด **นำกลับมาแสดง** ได้ รายการยังเป็นเสร็จสิ้น ไม่กลับเข้าคิว

วันที่ เวลาแต่ละ stage รหัสคิว การเช็คอิน ลิงก์ติดตาม และประวัติผู้ทำรายการยังอยู่ การเก็บรายการไม่คืน slot ที่ใช้งานไปแล้ว และไม่ส่งอีเมลใหม่

กรณีไม่มา/ยกเลิกก่อนเสร็จ ให้ใช้เอาออก/ยกเลิกกับแท็บรายการยกเลิกตามเดิม ซึ่งคืนที่ว่างและคืนการจองเมื่อมีที่ว่างได้

## เทส: ลบเฉพาะรายการ

ปุ่ม **ลบข้อมูลทดสอบ** อยู่ในรายการและหน้ารายละเอียด รวมรายการจบแล้วหรือที่เก็บประวัติ:

1. กดปุ่มแล้วตรวจชื่อนักเรียน รหัสคิว วัน และรอบในหน้าต่าง
2. ติ๊กยืนยันว่าต้องการลบถาวร
3. กด **ยืนยันลบข้อมูลทดสอบ**

ลบการจอง งานเมลและประวัติของรายการนั้น คืน slot และลิงก์ติดตามเดิมใช้ไม่ได้ รายการอื่น/รหัสคิวอื่นไม่เปลี่ยน ไม่ย้อนเลขคิว เพื่อไม่ใช้รหัสซ้ำ หากลบ Calling/Serving ห้องทดสอบจะว่างลงด้วย

## เทส: เคลียร์งานปัจจุบันเพื่อเริ่มใหม่

1. Staff กด **ล้างงานทดสอบนี้** ด้านบน
2. อ่านจำนวนรายการและงานที่จะล้าง รวมรายการใช้งาน จบแล้ว เก็บประวัติ และยกเลิก ทั้งงาน ไม่ใช่เฉพาะตาม Filter
3. พิมพ์ **CLEAR TEST DATA** แล้วกด **ยืนยันล้างงานทดสอบนี้**

ล้างการจอง คิว ประวัติ และ outbox ของ event ปัจจุบัน พร้อมเริ่มเลขคิวใหม่ที่001 ลิงก์เดิมใช้ไม่ได้ เก็บตาราง slots, config, Username/Password ทั้ง7, APP_SECRET, session/Login และฐานข้อมูลไว้ งานอื่นที่อยู่ในฐานเดียวกันไม่ถูกล้าง

หากมีคนจองหรือ Staff อีกคนเปลี่ยนข้อมูลระหว่างเปิดหน้าต่าง ระบบจะปฏิเสธเพื่อให้ปิดแล้วเปิดใหม่ก่อนยืนยันรายการล่าสุด หากมีงานส่งเมลค้าง active จะไม่ลบจนงานนั้นสิ้นสุด/หมด lease

## ขอบเขตป้องกันการลบในรอบจริง

ปุ่มและ API ลบเทสเปิดเมื่อ server รัน local-test, sample event ID ขึ้นต้น local-test-, database/user เป็น `warwick_consult_local_test` / `warwick_local_test`, hostเป็น db/localhost/127.0.0.1 และปิดส่งเมลเท่านั้น ตรวจฝั่ง Go server ไม่อาศัยซ่อนปุ่มอย่างเดียว ทุกคำขอต้องมี Staff session, CSRF, origin และ revision ที่ตรงกัน

Archive ใช้ Staff ทุกบัญชีได้และ audit ระบุผู้ทำรายการ การเพิ่มฟังก์ชันนี้ไม่เปลี่ยนสิทธิ์7บัญชีเดิม ไม่มีการแก้ schema migration เดิม

## อัปเดตโดยไม่ลบข้อมูลทันที

ดาวน์โหลด `Warwick_Staff_Manage_Test.sh` ไป Downloads เปิด Docker Desktop และ Terminal ในโฟลเดอร์โปรเจกต์เดิม:

```bash
bash ~/Downloads/Warwick_Staff_Manage_Test.sh
```

การรันตัวอัปเดตไม่ล้างการจอง ต้องกดและยืนยันจาก Staff เอง เปิดเว็บตามปกติที่ http://127.0.0.1:8080 และรีเฟรช ใช้ RD1/RD1 หรือบัญชีที่เหลือได้

ตัวรันนี้คงปิดส่งเมล เปิดครั้งถัดไปใช้ `bash scripts/queue-test.sh`; การตั้งค่ารอบจริง/ส่งเมลจริงยังรอขั้น Deploy

## ผู้ปกครองทำลิงก์ติดตามคิวหาย

1. Staff ค้นหาด้วยชื่อ / Wcode / Email แล้วกดชื่อนักเรียนเพื่อเปิดรายละเอียด ตรวจว่าตรงคนจากโรงเรียนและ Email
2. ในส่วน **ลิงก์ติดตามคิวของผู้ปกครอง** กด **คัดลอกลิงก์ติดตามคิว**
3. นำไปส่งให้ผู้ปกครองผ่านช่องทางที่ทีมใช้อยู่ เช่น LINE

เป็นลิงก์เดิม ไม่ออกคิวหรือรายการจองใหม่ และไม่ส่งอีเมลอัตโนมัติ ใช้ได้กับรายการที่ยังอยู่ในระบบ รวมรายการยกเลิก จบแล้ว และเก็บประวัติ หากลบข้อมูลเทสถาวรแล้วจะกู้ลิงก์นั้นไม่ได้

หากเบราว์เซอร์ปฏิเสธการคัดลอก ระบบจะเลือกข้อความในช่องลิงก์ไว้ให้ คัดลอกด้วย Cmd+C บน Mac หรือคัดลอกจากช่องเองบนมือถือได้ หากโหลดไม่สำเร็จให้กด **ลองโหลดลิงก์ใหม่**

ลิงก์ถูกเรียกเฉพาะเมื่อ Staff เปิดรายละเอียดของรายการนั้น ไม่แนบ token ทุกคนไปกับรายชื่อรวม ต้อง Login Staff ก่อน ทั้งโหมดเทสและรอบจริงใช้ฟังก์ชันนี้ได้ ขณะทดสอบด้วย localhost ลิงก์ยังเข้าจากอุปกรณ์อื่นไม่ได้จนกว่าจะตั้ง PUBLIC_URL ที่เข้าถึงได้ตอน Deploy
