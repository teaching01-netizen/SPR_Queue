# Export Excel สำหรับ Staff

## วิธีใช้งาน

เข้าสู่หน้า Staff ด้วยบัญชีเดิม แล้วกด **Export Excel** ข้างปุ่มรีเฟรช ระบบจะดาวน์โหลดไฟล์ `.xlsx` ที่เปิดด้วย Microsoft Excel, Numbers หรือ Google Sheets ได้

ปุ่มดึงข้อมูลล่าสุดจากฐานข้อมูล ณ เวลากด ครบทุกวัน ทุกระดับ ทุกวิชาในกิจกรรมปัจจุบัน ไม่ใช้ตัวกรอง การค้นหา หรือแท็บที่เปิดอยู่บนหน้าจอ รวมทั้งรายการยกเลิก รายการไม่มา รายการจบแล้ว และรายการจบแล้วที่เก็บออกจากหน้าทำงาน ข้อมูลที่ลบถาวรในระบบทดสอบไปแล้วจะไม่มีในไฟล์

## ข้อมูลในไฟล์

1. **ผู้ลงทะเบียนทั้งหมด**: หนึ่งแถวต่อการจอง รวม 39 คอลัมน์ ได้แก่ รหัสการจอง รหัสคิว Wcode ชื่อเล่น โรงเรียน Email ผู้ปกครอง ระดับ วิชาที่จอง วันที่ ช่วงเวลา รูปแบบการปรึกษา สถานะ วิชาปัจจุบัน ลำดับ Math/Verbal การเช็กอิน การยืนยันและช่วงเวลาสัมมนา คำถามทั้งสามข้อ เคาน์เตอร์ Staff เวลาลงทะเบียน/แก้ไข/จบ/ยกเลิก เหตุผลยกเลิก การเก็บรายการ สถานะอีเมล และเวลาเรียก/เริ่ม/จบของทั้งสองวิชา
2. **สรุปช่วงเวลา**: แยกตามวัน ระดับ วิชาที่จอง และช่วงเวลา แสดงจำนวน Slot ยอดลงทะเบียนทั้งหมด ยอดใช้ Slot เช็กอิน และจำนวนแยกตามสถานะ รวมรอบที่ยังไม่มีผู้จองด้วย Math + Verbal เป็นกลุ่มแยกต่างหาก

เวลาบันทึกทุกช่องแปลงตามเขตเวลาของกิจกรรม (`Asia/Bangkok`) ส่วนวันที่/ช่วงเวลา Consult เป็นช่วงที่จอง ไม่ใช่การนัดหมายรายบุคคล 10 นาที หากเป็นรอบเก่าที่ไม่อยู่ในตารางปัจจุบัน จะแสดง `รอบเดิม` พร้อมรหัสรอบเพื่อไม่เดาเวลา

ยอดลงทะเบียนทั้งหมดรวมรายการยกเลิก ยอดใช้ Slot ไม่นับรายการยกเลิก แต่ยังนับรายการจบแล้วและไม่มาตามกติกาจองเดิม จำนวนเก็บออกจากรายการเป็นส่วนหนึ่งของประวัติ ไม่ควรนำไปบวกซ้ำกับยอดรวม

ไฟล์ตรึงหัวตาราง เปิดตัวกรอง และตัดบรรทัดข้อความยาวไว้ให้ Wcode/รหัสคิวคงเลขศูนย์นำหน้า คำถามที่ขึ้นต้นด้วย `=` จะเป็นข้อความ ไม่มีการรันสูตร ข้อมูลผู้ลงทะเบียนไม่มีรหัสผ่าน session หรือกุญแจ/ลิงก์ติดตามคิวส่วนตัว

## ติดตั้งอัปเดตบน Railway

1. แตก `SPR_Queue_Staff_Excel_Update.zip`
2. อัปโหลดโฟลเดอร์ `backend`, `frontend`, `docs` ที่อยู่ภายใน ZIP ทับที่ root ของ Repo `teaching01-netizen/SPR_Queue` แล้วกด Commit changes
3. รอ Railway Deploy ขึ้น Success แล้วรีเฟรชหน้า Staff

ไม่ต้องเพิ่มตัวแปร ไม่ต้องแก้ Apps Script หรือตารางฐานข้อมูล การ Export เป็นการอ่านข้อมูล ใช้ได้ทั้งรอบทดสอบและรอบจริง Staff ทั้ง Admin และ Operator ดาวน์โหลดได้หลังล็อกอิน ข้อมูลการจองและลำดับคิวไม่เปลี่ยนจากการ Export
